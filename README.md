# 🎬 Bollywood Hangman

A Bollywood movie-themed Hangman game built using Python.

## 🎮 How to Play

Guess the Bollywood movie one letter at a time before the hangman is completed.

### ✨ Features

- 🎬 Bollywood movie titles ranging from your grandparents era to yours 
- 🔤 Letter-by-letter guessing
- 🧍 Hangman ASCII art
- 🏆 Win and lose conditions

#### 🛠️ Technologies Used

- Python

##### ▶️ How to Run

Run the following command in your terminal:

```bash
python3 "Hangman Game.py"
